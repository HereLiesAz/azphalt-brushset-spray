# azphalt-brush-spray-kit

Brush packages for the "spray-kit" collection, each in its own `brushes/<slug>/` folder (manifest.json + LICENSE + assets/tip.png):

- `brushes/spray-fat-cap/` — **Fat Cap** — A wide, dense spray-can cap — heavy atomized coverage for filling large areas.
- `brushes/spray-skinny-cap/` — **Skinny Cap** — A narrow spray-can cap for fine lines and tight detail work.
- `brushes/spray-fade/` — **Fade** — A soft atomized mist that fades smoothly to nothing — for gradients and blends.
- `brushes/spray-halo/` — **Halo** — A ring-shaped spray cap for outlines, halos, and edge work.

`node build.js` packs every subfolder into its own `.azp`.
